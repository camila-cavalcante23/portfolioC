## 📖 Sobre o Projeto

Este projeto foi construído do zero utilizando **React** com **Vite**, focando em performance, organização de código e uma experiência de usuário (UX) fluida.

O objetivo principal é centralizar meus projetos acadêmicos e profissionais, demonstrando na prática minhas habilidades em desenvolvimento web, desde a concepção de interfaces responsivas até a integração de lógica de componentes.

## ✨ Funcionalidades

* **⚡ Navegação SPA:** Transição suave entre seções (Smooth Scroll) sem recarregamento da página.
* **📂 Galeria de Projetos Dinâmica:**
    * Filtragem por categoria (Front-end, Full Stack).
    * Lógica de "Ver mais/Ver menos" para manter a interface limpa.
    * Cards detalhados com tags de tecnologias e status do projeto.
* **🛠 Seção de Habilidades Interativa:** Cards animados com efeito cascata e "Tech Badges" modernas.
* **📱 Design Responsivo:** Layout totalmente adaptável para Mobile, Tablet e Desktop.
* **📧 Contato Inteligente:** Integração direta com API do Gmail para envio rápido de mensagens preenchidas.
* **⬆️ Botão Scroll-to-Top:** Funcionalidade de UX para retornar ao topo da página facilmente.

## 🛠️ Tecnologias Utilizadas

* **React.js (Vite):** Estrutura principal e componentização.
* **CSS3 (Variáveis CSS):** Estilização customizada com tema de cores consistente (Dark/Purple Theme).
* **React Icons:** Biblioteca de ícones vetoriais.
* **Intersection Observer API:** Utilizada para animações de entrada dos elementos na tela.

## 🚀 Como Rodar o Projeto

Pré-requisitos: Você precisa ter o [Node.js](https://nodejs.org/) instalado em sua máquina.

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/camila-cavalcante23/portfolioC.git](https://github.com/camila-cavalcante23/portfolioC.git)
    ```

2.  **Entre na pasta do projeto:**
    ```bash
    cd portfolioC
    ```

3.  **Instale as dependências:**
    ```bash
    npm install
    ```

4.  **Rode o servidor de desenvolvimento:**
    ```bash
    npm run dev
    ```
